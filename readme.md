## VDH_media_center

This software allows you to search YouTube, download videos, or even play videos if you want. I created this software to help you conveniently watch YouTube videos without worrying about where to listen to them.

---

### Instructions:

After downloading, please extract the file. Note: If your antivirus software scans the exe file, please turn off your antivirus software. Find the VDH media center.exe file to start a software window.

After running, an interface will appear with the following functions:

- PlayYouTubeLink: This function allows you to paste the YouTube link so you can listen. It includes a Play (Default Player) button to listen directly within the software interface. Play in Browser allows you to open it directly in your browser.
- Play a direct link: You can watch videos directly from YouTube or sites that support stream links.
- Download from Link: This function allows you to paste links from YouTube, Facebook, TikTok, Instagram, SoundCloud to download audio/video. When you paste the link to the entire playlist, it will download the entire playlist. Note: Downloading the playlist takes quite a long time. You can currently download MP4, WebM, MP3, WAV, M4A, and OGG format options. Additionally, you can also download videos/audios from supported sites.
- Search on YouTube: This function allows you to search for a song or video of your choice. When you press this button, a "Enter keyword to search" box will appear where you can enter your desired result. For example, the result might be "hello". After entering the result, find the search button and press it. When you press the search button, another interface will appear where you can use the up and down arrow keys or navigate with your mouse to browse through the list boxes. After finding the desired result, press it again, and the options interface will appear. You can do whatever you want with this interface; you can play, download, or copy the video link to your clipboard.
  - Search History: Search history will be stored for convenient searching.
- Favorite Video: A list of favorite videos will appear when clicking this button. If there are no favorite videos, you will be prompted.
- Your collection: You can watch your favorite collections with the best videos.
- Watch History: Review the history of videos you've watched before.
- Play Queue: Shows the songs waiting to play. Add songs from the context menu of a list (Add to queue) or from the Options menu of the player. The queue plays in the order the songs were added and each song is removed from it when it starts. When the queue is empty, playback goes back to the list you were listening to, with the song after the one that was playing before the queue. Press alt+up / alt+down in the queue window to change the order. Press enter on a song to play it (control+enter plays it as audio); the applications key or shift+f10 opens the same context menu as the YouTube results, with Remove from queue instead of Add to queue. The window also has a Clear all queue button and a Close button.
- Download Queue: This allows you to download music from the queue to your computer.
- Listen to Audio File: You can listen to music with files already on your computer.
  - Add File: listen a file.
  - Add Folder: listen A folder with many files inside.
- Recent Files (alt+e): Shows the audio files you listened to recently. Press enter to play a file again; it continues from where you stopped if Resume is turned on in settings. Press delete to remove the selected file. The window also has Remove selected, Clear all and Close buttons. Audio files from your computer are kept here instead of in Watch History.
- Recent Folders (alt+o): Shows the folders you listened to recently, together with the last file you played in each one. Press enter to continue listening to that folder.
- Radio Player (alt+r): Listen to radio stations from all over the world. First choose to browse by country or by language and pick one from the list, then type a name in the search box (leave it empty to see the most popular stations) and press enter on a station to play it. If the connection to a station drops, the application tries to reconnect by itself. Use Change country (alt+g) to pick another country or language.
- Favorite Stations (alt+v): Opens the radio stations you added to your favorites. Press enter to play one, press delete to remove it, or use Clear all favorites.

In the main interface of the software, you can press the Alt key to open the help menu. In this menu, you can view the software's information, read the readme, and contact the main developer.

### settings

You can customize your favorite features in this settings section. Press F1 on any option to hear a short description of it.

## General  tab

This tab will give you a few options:

- Application language(requires restart): You can choose the language that is easiest for you to understand.
- Automatically check for updates on startup: the app looks for a newer version every time it opens.
- Start program automatically after login: the app launches by itself when you sign in to Windows.
- Automatically detect YouTube links in clipboard on launch: if you have copied a YouTube link, the app offers to use it as soon as it starts.
- Automatically check for yt-dlp updates on startup: keeps the download engine (yt-dlp) up to date so that downloading and searching keep working.
- Turn off sound in application: If you're feeling too dissatisfied with the sound system, this option will solve that problem.
- show logo when the application start: If selected, the logo sound will be on, and off if you deselect it.
- Remember where I stopped in each audio file (Resume): when you open an audio file from your computer again, it continues from where you stopped. Each file remembers its own position.
- Show license confirmation when the application starts: when selected, the license is confirmed each time the application starts: the door sound is played and you hear that the license is accepted. When cleared, the door sound is not played and the application opens straight away.

## Player  tab

In this tab there will be a number of options used for the music player:

- Audio Output Device: choose which sound device (speakers, headphones...) the player uses.
- Skip silence (Recommended only for music): automatically jumps over silent parts of the audio.
- Equalizer: choose a preset (Off, Flat, Classical, Rock, Pop...) to adjust the sound tone, such as bass and treble, to suit the kind of audio. You can also press control+e in the player to open the Equalizer window, where you choose a preset or choose Custom to set the preamp and each frequency band yourself. Use the left and right arrow keys on a slider to change it by 1 dB, page up and page down by 5 dB. The Reset (flat) button puts every slider back to zero.
- Normalize volume (keeps the loudness even between tracks).
- Seeking Announcement Mode: chooses what you hear when you rewind or fast forward.
  - Silent: nothing is announced.
  - Read percentage: announces the new position as a percentage of the video.
  - Read time: announces the new position as a time.
- After Video Finishes: chooses what the player does when a video ends.
  - Close the player: closes the player window.
  - Replay video: plays the same video again.
  - Do nothing: the player stays open and nothing happens.
- Fast Forward Interval (Seconds): how many seconds the right arrow key jumps forward.
- Rewind Interval (Seconds): how many seconds the left arrow key jumps back.
- Continue watching (Resume from last position): when you open a video again, it continues from where you stopped.
- Save watch history: records the videos you watch so they appear in Watch History.
- Save search history: keeps your search keywords so they appear in Search History.
- Play button action: chooses which player opens when you press the Play button.
  - Play with the computer's default player: opens the video in the media player installed on your computer.
  - Play with the application's default player: plays inside the app's own player.
- Audio channels: Chooses how the left and right audio channels are played: normal stereo, swapped channels, only the left ear, only the right ear, or mono (both channels mixed together). The change is applied to the music immediately.
  - Stereo (Normal): It is applied default.
  - Reverse stereo: Swap left and right channels.
  - Left ear only: Left channel to the left speaker, right speaker silent.
  - Right ear only: Right channel to the right speaker, left speaker silent.
  - Mono: All channels will be merged into one channel.
- Auto pan audio (Ctrl+Left / Ctrl+Right are disabled): When selected, the music pans by itself, moving slowly between the left and right ears while it plays, with nothing to press. Ctrl+Left and Ctrl+Right do nothing while this option is on. Clear this option to pan by hand again.
- Auto pan cycle time (seconds, 1 - 60): how many seconds one full sweep from left to right and back takes. It can only be changed while Auto pan audio is selected.

## Radio  tab

In this tab you can customize how radio stations are recorded. To record the station you are listening to, press control+r in the radio player; press it again to stop. Recordings are saved with the station name and the date and time.

- Recording Folder: shows the folder where recordings are saved (by default the radio_recording folder in the application folder). It cannot be typed in.
  - Change Path: pick another folder for recordings.
  - Reset to Default Directory: goes back to the default radio_recording folder.
  - Open Recording Folder: opens the folder in Windows Explorer.
- Recording format: choose MP3, M4A, OGG or WAV.
- Recording bitrate: the quality of MP3, M4A and OGG recordings. A higher number sounds better and makes a bigger file. WAV is not compressed, so it ignores this setting.
- Recording channels: record in stereo or in mono (half the file size).
- Sample rate: choose the sampling rate, or keep the one the station uses (Same as the station).
- Stop recording automatically after (minutes, 0 = never): the recording stops by itself after this many minutes.
- Recording volume (0-100): how loud the recordings are. 100 is the full volume of the station.

## Search tab

In this tab you can customize search settings:

- Automatically search after voice input: searches right after you finish speaking, without pressing the search button.
- Enable typing sounds in search box: plays a sound for each key you type in the search box.
- select typing sound: choose which sound is played while typing.

## Data  tab

In this tab there will be a few options related to configuration data:

- Backup Configuration: saves your current settings to a file for safekeeping.
- Restore Configuration: loads your settings back from a backup file you saved earlier.

## Shortcuts tab

In this tab you can change the keyboard shortcuts to the keys you like.

- Show shortcuts for: choose whether the list shows the shortcuts of the main window or of the player.
- Shortcuts list: use the up and down arrow keys to choose an action and press enter to change its shortcut.
- Change...: opens a window where you press the new keys for the selected action, or choose them from a list.
- Reset this one: sets the selected action back to its original shortcut.
- Remove: removes the shortcut of the selected action.
- Reset all shortcuts: sets every shortcut of the main window and the player back to the original keys.

## download tab:

In this tab you can customize some actions:

- download path edit box read only: shows the folder where downloads are saved. It cannot be typed in; use the change path button to pick another folder.
- change path button: lets you pick a different folder for downloads.
- reset path to default button: goes back to the default download folder.
